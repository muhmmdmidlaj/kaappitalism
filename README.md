# Kaappitalism

A premium e-commerce lifestyle & apparel brand platform built with React, Vite, TypeScript, and Tailwind CSS.

## Features

- **Split Category Architecture**: Curated fashion apparel and artisanal coffee selections.
- **Dynamic Shopping Cart**: Cart drawer with quantity controls, subtotal calculations, and interactive state management.
- **Modal Integrations**: Product details, editorial articles, checkout, store directions, and customer policies.
- **Micro-Interactions & Motion**: Smooth scrolling, toast notifications, confetti checkout celebrations, and responsive navigation.

## Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/muhmmdmidlaj/kaappitalism.git
   cd kaappitalism
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
